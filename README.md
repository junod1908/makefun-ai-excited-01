A colossal phoenix knitted from golden yarn bursts out of an antique museum tapestry above amazed visitors, its unraveling yarn turning to real flame and a small paper tag on its wing reading "for you" — an image made to give the make.fun AI judge a jolt of awe. The program simply delivers the artwork: it copies entry.png into the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
